# 图片处理器 v2.6 性能实测

测试机使用 Windows x64 和 MATLAB R2025b Update 1。编辑测试在 v2.5 和 v2.6 中打开同一张 1280 × 1932 像素的照片，用相同的参数和笔迹操作可见窗口。每版打开三个新窗口，计时包含图形刷新。下表为中位数，连续操作按每轮的实际总时间取中位数。

| 操作 | v2.5 | v2.6 |
|---|---:|---:|
| 新建 MATLAB 进程到首屏「打开照片」可用 | 16.28 秒 | 14.79 秒 |
| 在空窗口中打开第一张照片 | 2.04 秒 | 1.88 秒 |
| 在结果视图调整一次锐化强度 | 244 毫秒 | 125 毫秒 |
| 在结果视图调整一次曝光 | 338 毫秒 | 271 毫秒 |
| 在频谱上提交一笔并刷新 | 792 毫秒 | 35 毫秒 |
| 连续画四笔、擦一笔，再切回照片 | 4.11 秒 | 0.90 秒 |
| 同一组操作，再导出原尺寸 PNG | 5.16 秒 | 2.09 秒 |

画笔在频谱上先显示每一笔的蒙版，切回照片时统一计算累积笔迹。单看画完后切回照片，这一步由 0.04 秒变为 0.70 秒。本轮在结果视图单独导出 PNG 由 0.92 秒变为 1.19 秒。连续画多笔时省下的时间大于这两步增加的时间。第一轮的调整预览和画笔预览与 v2.5 逐像素相同。三轮导出的 1280 × 1932 RGB PNG 分别读回比较，每一轮的像素差都是 0。

## 首次进入功能页

计时从选择标签开始，到所选页的主要控件可交互、画面刷新为止。每轮轮换访问顺序，以三轮中位数汇总。再次打开已创建的页面也单独计时。

| 功能页 | v2.5 首次 | v2.6 首次 | v2.5 再次 | v2.6 再次 |
|---|---:|---:|---:|---:|
| 频域实用工坊 | 1.383 秒 | 0.430 秒 | 0.048 秒 | 0.108 秒 |
| 扩展应用 | 0.944 秒 | 0.510 秒 | 0.045 秒 | 0.030 秒 |
| 空间采样 | 1.380 秒 | 0.855 秒 | 0.068 秒 | 0.050 秒 |
| 栅栏图像错觉 | 0.596 秒 | 0.558 秒 | 0.035 秒 | 0.035 秒 |

## 启动口径与复核

每个版本交错启动三个新的 MATLAB 进程，保留操作系统缓存。v2.5 三次为 12.92、16.28、18.08 秒，v2.6 为 14.79、15.48、13.39 秒。启动计时从 MATLAB 进程创建开始，本机测试宿主被 Windows 启动器的完整性检查拦住，因此没有从双击 EXE 开始的计时。日常双击使用还包含启动器和 MATLAB 初始化时间。

同一张照片上反复调整参数时，v2.6 会复用未改变的滤波阶段。38 组照片回归的 489 项逐像素断言、39 组内核对照和 6 个计时用例的输出对照均通过。在真实编辑窗口中也复核了绘制、擦除、撤销、重做、清空以及全尺寸导出。

## 数值输入与方向键

36 个滑块均配有数值框，涵盖 18 个基础调整、15 个创意和画笔参数，以及对比分界、水印强度和栅栏位置。输入数字后按 Enter 提交，聚焦滑块后用 ← / → 按参数步长调整。在 R2025b 上已检查输入、拖动、撤销重做、重置、动态范围及禁用状态，并对两个编辑器滑块连续发送实体方向键。焦点进入数字框后，方向键移动输入光标。旧版滑块的兼容分支已在 R2025b 强制启用并测试，R2020b 本身未实测。

基准入口位于 `deploy/bench_interaction_v26.m`、`deploy/check_kernels_v26.m` 和 `deploy/check_pages_v26.m`。同一工作区的 `v2.6-验证` 目录保留了原始计时、像素对照和各项日志。
