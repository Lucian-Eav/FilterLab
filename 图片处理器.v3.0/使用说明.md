# FilterLab v3.0 · Windows 独立版

## 在没有 MATLAB 的电脑上使用

v3.0 面向 Windows x64。接收方用免费的 MATLAB Runtime 运行图片处理器，无需安装 MATLAB 桌面或购买许可证。本次提供在线安装包。

1. 将发布包完整解压到纯英文路径，例如 `C:\FilterLabSetup`。联网后双击 `FilterLab_3_0_Online.exe`。按向导安装应用和匹配的 Runtime，安装目录选用纯英文路径，例如 `C:\Apps\FilterLab` 和 `C:\Apps\MATLABRuntime`。Windows 可能提示管理员授权。
2. 安装结束后从开始菜单打开 FilterLab，点击「打开照片」。也可以把一张图片的绝对路径作为参数传给安装目录里的 `FilterLab.exe`。
3. 题目六问的报告默认写到 `%LOCALAPPDATA%\FilterLab\output`，照片通过导出对话框保存到所选目录。首次启动可能因 Runtime 初始化和资源解压而较慢。

Runtime 需与构建所用 MATLAB 为同一发行版，更新级别至少与构建端相同。当前工程使用 R2025b。详见 [MathWorks Runtime 安装说明](https://ww2.mathworks.cn/help/compiler/install-the-matlab-runtime.html)。

## 开发者构建安装包

在装有 MATLAB R2025b 和已授权 MATLAB Compiler 的 Windows x64 构建机上，从本目录运行以下命令。默认生成在线安装包。

```cmd
构建安装包.cmd online
```

若 MATLAB 安装在非默认目录且不在 PATH，可先设置 `FILTERLAB_MATLAB_EXE`，如本机 `set "FILTERLAB_MATLAB_EXE=D:\MATLAB\bin\matlab.exe"`。需要离线安装包时，将 `online` 改为 `offline`，或用 `both` 同时生成两种。离线打包需要与编译所用 MATLAB 更新级别匹配的完整 Runtime 安装文件。

每次构建保存在 `dist\<构建编号>\`。`standalone\FilterLab.exe` 是独立应用，`online\` 或 `offline\` 存放给用户的安装包。成功后 `build.json` 记录实际文件名。单独复制 EXE 时，目标机需要先安装兼容的 Runtime。

## 在目标机验收

在一台只装匹配 Runtime 的 Windows x64 电脑上安装应用，从程序目录运行 `用户验收.cmd`。也可以显式指定 EXE 路径。

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\deploy\runtime_check.ps1 -ExePath 'C:\实际安装目录\FilterLab.exe'
```

验收覆盖 5 张首页资源、照片处理与导出、降采样、16 相分解重建和六问报告。检查程序要求 `Deployed=1`、`Packaged=1`，并解码导出图片、检查报告插图和结果文件。每轮记录保存到 `%LOCALAPPDATA%\FilterLab\acceptance` 下的新目录。

## 从 MATLAB 阅读或运行源码

将 MATLAB 当前目录切换到 `app` 并运行 `FilterLabApp`。源码自测可执行 `FilterLabApp('--self-test')`。此模式的回执会记录 `Deployed=0`。照片、滤波器和实验功能参见[功能说明](app/README.md)。
