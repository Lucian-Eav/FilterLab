## 这是什么

FilterLab 把「修照片」和「讲清滤波」放进同一个软件。左边是自然 RGB 照片的曝光、白平衡、去噪、锐化与裁剪，右边是能看到频谱、能在频谱上落笔的滤波器实验台。切换工作区时，当前照片的参数和历史都会保留。

四个工作区覆盖了从日常修图到课程作业的全部场景：

| 工作区 | 能做什么 |
|---|---|
| 🖼 **照片与创意编辑** | 曝光、白平衡、去噪、锐化、裁剪旋转；频域画笔抑制指定频率，局部蒙版限制作用范围；前后对比、撤销重做、保存参数、导出照片 |
| 📐 **题目滤波实验** | 一维滤波器六道实验题，一次导出 HTML 报告、六幅图和可复现的计算结果 |
| 🧪 **扩展应用实验** | 摩尔纹与抗混叠、作业纸去横线与阴影、方向性运动去模糊、全通相位置乱与解密 |
| 🛠 **频域实用工坊** | 连拍对齐与堆栈、按清晰度挑片、隐形水印嵌入与检测、光圈星芒与散景模拟 |

核心处理**不依赖 Image Processing Toolbox 或 Signal Processing Toolbox**，只用到基础 MATLAB。

## 几个实测数字

| 版本 | 指标 | 变化 |
|---|---|---|
| v2.1 | 12 项代表任务的中位耗时之和 | **3.100 s → 2.071 s**（−33.2%） |
| v2.1 | 启动器新建进程到空载窗口就绪 | **17.598 s → 12.693 s** |
| v2.6 | 频谱单笔刷新 | **792 ms → 35 ms** |
| v2.6 | 连画四笔 + 擦一笔 + 切回照片 | **4.11 s → 0.90 s** |

提速来自三处改动：只计算启用的频带、局部画笔只重算覆盖区域、实验页首次进入时才加载控件。v2.6 起把笔迹计算推迟到「切回照片」这一步，换来绘制过程近乎即时。

## 快速开始

### 方式一：直接用 v3.0 独立版（无需 MATLAB 许可证）

1. 下载 [图片处理器.v3.0/FilterLab-3.0-Windows-x64.zip](图片处理器.v3.0/FilterLab-3.0-Windows-x64.zip)，解压到**纯英文路径**（如 `C:\FilterLabSetup`）。
2. 联网后双击 `FilterLab_3_0_Online.exe`，按向导安装应用与 MATLAB Runtime，两者也请选**纯英文安装目录**。
3. 从开始菜单打开 FilterLab。

需要 MATLAB Runtime **R2025b（Update 1 或更高）**，安装包会自动获取。详见 [v3.0 使用说明](图片处理器.v3.0/使用说明.md)。

### 方式二：用 v2.x 启动器版（需本机 MATLAB R2020b+）

1. 把整个版本文件夹放到固定位置，双击 `创建桌面快捷方式.exe` 建立桌面图标。
2. 双击桌面图标或 `FilterLab.exe`；首次启动等待 MATLAB 初始化，不会打开 MATLAB 编辑器。
3. 若未自动找到 MATLAB，按提示选择安装目录下的 `bin\matlab.exe`。

> 建议放在普通用户目录（如 `D:\FilterLab\`）。从 Windows 受限制或低完整性的工作区启动时，系统会阻止 MATLAB 初始化。

### 方式三：从源码运行

在 MATLAB 中把当前文件夹切到任意版本的 `app` 目录（如 `图片处理器.v3.0/app`），然后：

```matlab
FL_gui                        % 主入口（等价入口：FL_photo、FL_main）
FL_photo('File', 'my.jpg')    % 直接打开某张照片
```

兼容目标 MATLAB R2020b+，实际验证环境为 **R2025b Update 1**。

## 构建 Windows 独立版

在装有 MATLAB R2025b 与 MATLAB Compiler 的 Windows x64 机器上，从 `图片处理器.v3.0` 目录运行：

```cmd
构建安装包.cmd online     :: 默认，生成在线安装包
构建安装包.cmd offline    :: 内含完整 Runtime 的离线包
构建安装包.cmd both       :: 两种都生成
```

每次构建输出到 `dist\<构建编号>\`：`standalone\FilterLab.exe` 是可单独复制的应用（目标机需预装兼容 Runtime），`online\`、`offline\` 下是给用户的安装包，`build.json` 记录实际文件名。MATLAB 不在默认目录时可先 `set "FILTERLAB_MATLAB_EXE=D:\MATLAB\bin\matlab.exe"`。

## 环境与兼容性

| 项目 | 要求 |
|---|---|
| 操作系统 | Windows x64（v2.x 与 v3.0 的打包版）；源码另可在 MATLAB 支持的平台上运行 |
| 源码运行 | MATLAB R2020b 或更新；实测 R2025b Update 1 |
| 独立版运行 | 仅需免费 MATLAB Runtime R2025b（Update 1+），无需 MATLAB 许可证 |
| 构建安装包 | MATLAB R2025b + 授权 MATLAB Compiler |
| 工具箱依赖 | 核心功能无；不依赖 Image Processing / Signal Processing Toolbox |

**已知限制**：v3.0 已在开发机以编译模式完成首页资源加载、照片处理与导出、降采样、16 相重组及六问报告验收，独立进程正常退出；但在**从未安装过 MATLAB 的电脑上从零安装到首次启动**这一步仍待实测。
