## 代码检查与精简

- **复用有效缓存**：构图未变化时复用原图缩略预览；原图频谱缩略图与笔刷衰减显示分开缓存。调色等无关参数不重做原图 FFT，笔刷变化只更新频谱叠加层，几何变化失效相关缓存。
- **避免重复工作**：相同状态直接返回；小于预览上限的照片复用完整尺寸结果供 100% 和导出使用；调用方不要求诊断结果时，流水线不构造基础处理的残差图。
- **集中交互出口**：工具选择、停止绘制、切换视图统一调用现有状态更新和渲染路径，移除重复 `publish`/刷新。修复从频谱进入残差时未正确切到完整分辨率，以及工具下拉框与标签不同步的问题。
- **复用实验界面**：嵌入式和独立窗口调用同一个实验组件，避免复制六问计算与界面。照片适配滤波与原题共享设计来源，但各自明确处理口径。
- **统一验证与清理**：所有八组测试进入同一个验收入口，动态汇总通过数。删除两份已执行的一次性 Python 界面代码生成脚本；已确认源代码和文档不引用它们。

缓存行为、可选输出及切换修复有新增回归覆盖。没有为减少行数而压缩算法含义或引入新的框架依赖。

## 六问计算口径

使用题目原始 32×32 x/xn，xn 保留约 −0.6064～1.4407。Wc=0.4、阶数 10/4/12、FIR 频带 [0 .36 .44 1]；先行后列、零初态、无预填充、无 DC 归一化、无计算值裁切。

当前环境没有可调用的 `butter`、`remez`、`firpm`。Butterworth 使用解析实现，FIR 使用固定原题 Parks–McClellan 参考系数，稠密网格交替极值数为 4/8；报告明示来源。原生 Signal Processing Toolbox 分支未在本机运行。导出的独立复现脚本已运行并与结果数组核对一致。

Butterworth 绝对阶跃超调 0.216559 最大；4/12 阶 FIR 每轴延迟 2/6 像素，IIR 本图整体位移估计 [5,5]。12 阶 FIR 的原坐标及同域延迟补偿 MSE 最小，额外校正增益后 4 阶 FIR 最小。数值与上一版一致，完整解释见 [题目实验说明](题目实验说明.md)。

## 验证边界

GUI 使用真实控件回调、公用动作、MATLAB `matlab.uitest.TestCase.drag` 事件和截图验证；没有自动点击操作系统原生打开/保存对话框。此前 Java Robot 桌面指针测试受外部干扰中止，不计入通过数。静态检查仍有格式、日期函数建议和嵌套清理函数的保守提示；忙状态与失败恢复路径已测试。

照片按 sRGB 解释，无 ICC 转换、RAW 显影或深度学习去噪。自动估噪和保边多尺度是图像相关非线性操作，不声称具备实验 FIR 的全局线性相位。频域强抑制可能振铃；单张照片运动模拟最多 41 次采样，长轨迹可能产生重复轮廓。

一般适应窗口先缩图再处理；自动估噪、频域或照片适配滤波开启时先处理完整尺寸。100% 和导出始终使用完整尺寸。PNG/TIFF 支持 16 位读写，GUI 导出 8 位；不复制 EXIF/GPS/ICC。历史最多 50 步，新照片或关闭后不保留；预设不保存构图和空间蒙版，载入时保留当前空间蒙版。
