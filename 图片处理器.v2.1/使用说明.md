# FilterLab 图片处理器 v2.1（Windows）

本包需要 Windows x64 和本机安装的 MATLAB R2020b 或更新版本。

## 使用

1. 完整解压到一个固定的普通文件夹，不要直接在 ZIP 内运行。
2. 双击 `创建桌面快捷方式.exe`。程序会根据当前解压位置，在你的桌面创建带青紫色图标的“图片处理器”；若已有同名快捷方式指向其他位置，会先询问是否更新。
3. 双击桌面的“图片处理器”，或直接双击 `FilterLab.exe`。首次启动需要等待 MATLAB 初始化，不会打开 MATLAB 编辑器。
4. 若没有自动找到 MATLAB，选择 MATLAB 安装目录中的 `bin\matlab.exe`。
5. 空载启动后，点“打开照片”选图，或点“进入编辑器”展开照片工具。也可以把照片拖到 EXE 上直接打开。第一张照片会触发编辑工具构建，之后在当前窗口里继续换图会复用它们。
6. 默认关闭窗口就退出 MATLAB。在无文件启动时，可以在启动提示窗勾选“快速重开”。此后关闭工作室会保留当前 MATLAB 引擎最多两分钟，占用相应内存。期间再次双击同一份 EXE 会打开新的工作室窗口。

必须让 `FilterLab.exe`、`filterlab-neon.ico` 和 `app` 文件夹保持相邻；不能只发送一个 EXE。快捷方式程序使用当前用户的真实桌面位置（包括重定向到 OneDrive 的桌面），不写死任何盘符。下载和解压本身不会自动创建快捷方式；需要双击一次创建程序。创建快捷方式不需要 MATLAB 或 Python；运行图片处理器仍需要 MATLAB。所有程序均不需要管理员权限，不修改 MATLAB 安装或系统 PATH。

请保留完整的解压文件夹，桌面快捷方式只是入口。如果移动了软件目录，在新位置重新运行 `创建桌面快捷方式.exe`，确认更新即可。新图标保存在 `filterlab-neon.ico`，不要删除该文件。

如果提示“低完整性工作区”，表示所在开发目录的 Windows 安全标签限制了 EXE。请把完整 ZIP 解压到普通用户文件夹，例如 `%LOCALAPPDATA%\FilterLab\Studio`，再运行里面的 EXE；不要直接运行开发工作区 `dist` 下继承了限制的构建副本。不需要关闭安全功能或修改原工作区权限。

自动查找 MATLAB 的顺序：包旁或用户配置的 `matlab-path.txt`、`MATLAB_ROOT` 环境变量、MathWorks 注册表、常规安装目录，最后检查构建机使用的 `D:\MATLAB`。文本配置一行写 MATLAB 的完整 EXE 路径即可。交付包不内置个人路径配置。

## 交互教程：从照片到频谱

打开照片，或在首屏点“进入编辑器”。在编辑器右侧选择“频域画笔”，点“交互教程：从照片到频谱”。如果已经将左侧视图切到“原图频谱”，也可以直接点画布上方的同名按钮。

**用八个周期看懂三个亮点。** 选择竖条纹，把周期数设为 8，保留全部频率。256 像素宽的图中，每隔 32 像素重复一次。傅里叶变换测量每个方向、每个频率的波有多强。中心亮点对应平均亮度，左右两点位于水平频率 ±8/256，即 ±0.03125 周期/像素。亮暗沿水平方向变化，所以两点水平排列。把周期数改成 16，两点到中心的距离随之加倍。

**检验相位和逆变换。** 回到 8 个周期，向右平移 8 像素，条纹就移动了四分之一个周期。幅度谱亮点的位置和强度保持一致。切换到相位，可以看到两个峰的相位向相反方向各转了 π/2。再用截止频率 0.02 的低通滤波，只保留中心亮点，逆变换后整张图变为均匀灰色。把截止频率升到 0.05，两侧峰也通过，条纹重新出现。

打开照片后，可以在教程中选择“当前照片”，并排看亮度图、频谱和逆变换结果。照片按当前构图取样，教程预览最长边为 256 像素，所有课堂操作都在该预览窗口内完成。

## 交互窗口

启动器使用支持交互窗口的 MATLAB 会话，允许“打开照片”“导出照片”“保存参数”“载入参数”调用系统文件对话框。旧版 20261119-130731 使用了批处理启动参数，虽然界面能显示，但打开文件选择框会报“非交互或禁用窗口显示”。请使用 20261119-134503 或其后继版本，并将旧桌面快捷方式更新到新版目录。

## 保存位置

照片和参数保存位置由你选择；不覆盖原照片或已有目标。

默认数据目录为 `%LOCALAPPDATA%\FilterLab`：六问报告写入其中的 `output`，启动和错误日志写入 `logs`，每次启动使用独立日志目录。

若用户数据目录不可写，启动器自动使用 EXE 旁的 `userdata` 目录，日志、报告和 MATLAB 路径配置均随之切换，不修改系统权限。也可在 EXE 旁创建空文件 `portable.flag`，始终使用便携模式。两个位置均不可写时，程序会提示将完整软件包解压到自己可写的目录。

`app\samples\plus.mat` 已包含六问需要的 x/xn，不依赖原工作区目录。分发包不含个人照片及开发输出。

## 自检

从命令行执行：

```text
FilterLab.exe --self-test --test-output "D:\空的测试输出目录"
```

自检通过同一个 EXE 启动 MATLAB，创建应用界面、处理与导出合成照片、运行六问、生成报告及截图，然后退出。成功退出码为 0，输出目录包含 `PASS.txt`；失败读取启动日志。测试输出目录必须为空。

## MATLAB 环境

本包通过 Windows 启动器调用本机安装的 MATLAB R2020b 或更高版本。运行照片处理器需要完整的 MATLAB 安装，仅安装 MATLAB Runtime 无法启动。

12 项处理耗时、启动耗时及一致性测试见本目录的《v2.1 更新与实测.md》。

EXE 未配置代码签名证书，Windows 可能显示未知发布者。请只使用可信来源的包，无需关闭系统安全功能。
