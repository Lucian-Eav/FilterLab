# 信号与系统扩展应用

在 MATLAB 中将当前文件夹切换到 `app`。运行 `FL_extensions_gui` 或 `FL_main('extensions')` 可打开独立实验窗口。也可以运行 `FL_photo`，点击主界面顶部的「扩展应用实验」标签。选择模块后，点击「运行当前模块」查看图像和实测指标。「运行全部四模块并导出」会生成一份统一报告。

## 四个实验怎么读

| 模块 | 实验与课程概念 | 参数与观察量 |
| --- | --- | --- |
| 1 · 摩尔纹与抗混叠 | 比较直接四倍抽样、因果预滤波和零相位预滤波。另用全分辨率 RGB 边缘测通道错位，用二维 FFT 定位拍屏干扰，再沿干扰方向做双向陷波。 | `MoireOpts.Order` 默认 6，`Cutoff` 默认 0.25。可用 `Frequency` 和 `Angle` 覆盖检测结果。频率 1 表示奈奎斯特频率，角度从图像水平向右顺时针计。 |
| 2 · 作业纸去横线与阴影 | 每行取灰度的 75% 分位数，用其频谱估计横线周期。沿列比较因果 IIR 的单侧拖尾与零相位 Remez 的笔画对称度，再估计慢变光照并归一化。 | `DocumentOpts.LinePeriod` 以像素为单位，省略时自动检测，GUI 中填 0。每节 FIR 的 `Order` 默认 48。背景低通 `Cutoff` 默认 0.03，范围 0.02～0.04。结果中的 `Causal` 保存因果 FIR，`CausalIIR` 对应图像和剖面的因果曲线。 |
| 3 · 动态追焦与方向性去模糊 | 用七点核比较 0°、30°、60° 三种运动模糊，再沿选定方向扫描五组 FIR 增强。对照山脊边缘放大图，观察阶跃超调增加时清晰度和振铃如何变化。 | `MotionOpts.Angle` 默认 30°。超调目标为 2%、10%、23%、40%、65%。`Sweep.Sharpness` 是梯度 RMS，`Sweep.Ringing` 是边缘附近超出原图局部灰度包络的 RMS。权衡曲线按各指标自身峰值归一化。 |
| 4 · 全通相位置乱与解密 | 行、列分别串联全通二阶节。观察单位幅度、非线性相位与功率谱，再比较正确密钥和扰动密钥的逆序时间反转解密结果。 | `AllpassOpts.Seed` 默认 3，每轴 `NumPairs` 默认 14 对、最多 24 对。`RadiusRange` 默认 [0.82, 0.94]。`DeltaRadius` 与 `DeltaAngle` 默认各为 0.01，分别表示极点半径增量和角度增量（弧度）。解密使用浮点密文 `Encrypted`。 |

## 命令行与输入照片

```matlab
R = FL_extensions();                      % 运行四个模块并导出，R.OutputDir 为报告目录
R = FL_main('extensions-run', 'Modules', [1 2], 'Export', false);
R = FL_extensions('Modules', 3, 'MotionOpts', struct('Angle', 45), 'Export', false);
disp(R.Results{3}.Sweep)
```

将自备的 `山脉.jpg` 或 `奶薯.jpg` 放入 `app/samples/`，再次运行实验即可。模块一的降采样和模块三共用山脉图，模块四使用奶薯图。程序会自动发现同名 JPEG 或 PNG，找不到时使用内置合成图。载入后最长边限制为 320 px，两边均须至少 32 px。

要指定其他路径、直接传灰度或 RGB 数组、或用 `'synthetic'` 选回合成基准，可分别设置 `MountainImage`、`MoireImage`（拍屏）、`DocumentImage` 和 `NaishuImage`。拍屏和作业纸的合成输入附有干净参考，可据此比较处理前后的 PSNR 和 SSIM。

## 导出与复现

默认导出到新的 `output/extensions-*` 目录。传入 `'OutputDir', folder` 可指定一个新目录或空目录。四个模块一起导出时包含以下文件。

| 文件 | 用途 |
| --- | --- |
| `report.html`、`summary.md` | 图文报告、各模块结论与指标 |
| `metrics.csv` | 带单位的实测指标表 |
| `results.mat` | 输入像素、参考数据、参数与计算结果 `R` |
| `reproduce_extensions.m` | 在 MATLAB 中运行此脚本，使用同目录的 MAT 文件重新计算 |
| 8 张 PNG | 每模块两张，依次展示抽样与陷波、横线与光照、模糊与增强、全通响应与解密 |

## 自动验收

```matlab
ok = fl_ext_selftest(true);
assert(ok, 'fl_ext_selftest failed');
```

`fl_ext_selftest()` 默认逐项打印 `[PASS]` / `[FAIL]` 和实测值。传入 `false` 可仅取返回值。数值验收固定使用内置合成基准，可以在放入个人照片后重复运行。全通敏感度依赖输入频谱与密钥，自检使用种子 3 的固定密钥。脚本还会执行原有核心自检，在临时目录核验 13 个导出文件，并打开两个隐藏窗口检查独立和嵌入式 GUI。临时报告与测试窗口会自动清理。
