## 1 软件概述

### 1.1 软件用途

本软件用于二维离散信号（图像）的可分离低通滤波实验与分析。它把一维离散
时间滤波器分别沿图像的行、列两个方向作用，用级联的方式完成二维滤波，并对
滤波结果从幅频特性、相频特性、群延迟、阶跃响应、几何失真、降噪与保真等
六个角度给出量化结论。

### 1.2 适用对象

- 信号与系统、数字信号处理课程的实验与分析；
- 需要比较不同滤波器（IIR 与 FIR、线性相位与非线性相位）在图像上的实际
  差异的教学与研究场景；
- 小尺寸图像的滤波算法验证——这类图像（几十像素见方）对相位失真与边界
  效应特别敏感，正是本软件的设计重点。

### 1.3 核心能力

| 能力 | 说明 |
|---|---|
| 滤波器设计 | Butterworth IIR 与等纹波线性相位 FIR，支持参数化 |
| 可分离滤波 | 行、列两个一维算子级联，方向顺序可切换 |
| 相位分析 | 通带群延迟均值与标准差，线性相位判定 |
| 阶跃响应 | 超调量、稳态值、过渡过程 |
| 几何失真 | 镜像交换误差、平移量估计 |
| 降噪评测 | PSNR、平坦区残余、边缘误差分解 |
| 参数扫描 | 一次调用遍历某个参数的全部取值 |
| 图形界面 | 参数设置、运行、浏览、导出 |
| 自检 | 六项数值不变量检查 |

### 1.4 设计取舍

**不依赖工具箱。** 软件自带一套与 MATLAB 同名函数等价的回退实现（`sl_` 前缀）。
在装有 Signal Processing Toolbox 的机器上优先调用内置函数，否则启用自实现
版本，两条路径的计算结果一致。这样做的原因是：课程作业与教学实验环境往往
只装了 MATLAB 本体。

**归一化到单位直流增益。** 等纹波设计是极小极大逼近，只在通带内逼近 1，直流
增益一般不恰好等于 1（本组默认参数下 b2 为 1.372、b3 为 0.850）。若直接比较
三个滤波器的输出图像，整体亮度差异会污染所有误差指标，因此统一把 H(1) 拉到 1，
原始系数另行保留。

## 3 安装与启动

### 3.1 安装

本软件为绿色免安装形式。将 `FilterLab` 整个目录复制到本机任意路径即可，
不需要运行安装程序，不写注册表，不需要管理员权限。

### 3.2 启动

在 MATLAB 命令窗口执行：

```matlab
addpath('D:\work\FilterLab')     % 换成软件所在路径
FL_main                          % 命令行模式，跑完整分析
```

或直接打开图形界面：

```matlab
addpath('D:\work\FilterLab')
FL_gui
```

### 3.3 目录要求

- `samples/` 目录内的 `plus.mat` 是自带样例数据，命令行模式的 `demo` 与界面
  模式的"样例数据"按钮都依赖它；
- `output/` 目录用于存放输出图片与报告，不存在时自动创建；
- 其余目录可只读。

### 3.4 路径与中文

软件自身支持中文路径。但由于 MATLAB 在**以中文目录作为启动工作目录**时会
报"文本字符无效"，建议采用下列任一方式：

1. 先在英文路径下启动 MATLAB，再用 `addpath` 添加中文路径下的软件目录；
2. 或把软件放在纯英文路径下使用。

**右栏（结果）** 为 2×3 的坐标区网格：

| 位置 | 内容 |
|---|---|
| 左上 | 原图 x |
| 中上 | 含噪图 xn（无噪声图时显示提示） |
| 右上 | b1 输出 |

左栏底部的文本框显示本次运行的完整文字结果，与命令行模式的打印内容完全一致。

### 4.2 典型操作流程

1. 启动界面，点击"样例数据"。软件载入 `plus.mat` 并按默认参数完成一次分析。
2. 观察右栏六幅图，确认三个滤波器的输出差异。
3. 修改左栏任一参数，点击"运行分析"重新计算。
4. 满意后点击"导出报告"，结果写入 `output/` 目录。
5. 若要分析自己的图像，点击"载入图像…"，选择 `.mat`、`.png`、`.jpg`、
   `.bmp` 或 `.tif` 文件。软件自动把位图转成双精度灰度矩阵。

### 4.3 参数改变时的注意事项

- **FIR 阶数必须取偶数**。软件的等纹波实现采用 Type I 线性相位结构，奇数阶
  不受支持，输入奇数会在运行时报错。
- **过渡带宽取太小会失败**。过渡带越窄，达到同样阻带衰减所需的阶数越高；
  阶数不足时等纹波迭代可能不收敛。
- **截止频率不宜接近 0 或 1**。接近 0 时有限阶设计难以逼近；接近奈奎斯特
  频率时低通几乎不起作用。
- **图像不宜过小**。当图像尺寸小于两倍滤波器阶数时，镜像交换误差与内部
  PSNR 会自动跳过，报告中显示为缺失。

### 4.4 界面与命令行的一致性

界面不实现任何算法，所有计算都转发给 `FL_main`。因此同一组参数下，界面
结果与命令行结果完全一致，便于复现和问题定位。界面的作用只是参数收集与
结果呈现。

## 6 功能模块详解

### 6.1 fl_spec —— 规格定义与校验

```matlab
S = fl_spec()
S = fl_spec('Wc', 0.3, 'N2', 6)
```

返回规格结构体并做参数校验。任何越界或类型不合法的参数都会立即报错，错误
信息中给出允许范围。校验前置的目的是：让错误在进入计算前暴露，而不是在
迭代中途产生难以定位的数值异常。

默认字段见附录 A。

### 6.2 fl_design —— 滤波器设计与相位判定

```matlab
F = fl_design(S)
```

返回 1×3 结构体数组，每个元素包含：

| 字段 | 含义 |
|---|---|
| `Name` | `'b1'` / `'b2'` / `'b3'` |
| `Type` | `'IIR'` 或 `'FIR'` |
| `Order` | 阶数 |
| `B`, `A` | 归一化后系数（满足 H(1)=1） |
| `Braw`, `Araw` | 原始系数 |
| `DCGain` | 原始系数的直流增益 |
| `Linear` | 是否严格线性相位 |
| `GDMean`, `GDStd` | 通带内群延迟均值与标准差 |
| `Band` | 设计用频带边界 |

相位判定使用两条独立证据：一是系数偶对称性 `max|B - fliplr(B)| = 0`，二是
通带内群延迟标准差是否为 0。两者同时成立才判为严格线性相位。

**注意**：对 IIR 而言，分子系数的对称性没有判别意义。偶数阶 Butterworth 的
分子恰好是回文多项式，逐项对称，但它显然不是线性相位——真正决定相位的是
分母的极点。软件对 IIR 直接给出说明，避免把"系数对称"误当成"线性相位"。

### 6.3 fl_filter2 —— 二维可分离滤波

```matlab
[Y, info] = fl_filter2(X, B, A)
[Y, info] = fl_filter2(X, B, A, 'Orient', 'cr', 'Edge', 'symmetric')
```

| 参数 | 取值 | 默认 | 说明 |
|---|---|---|---|
| `Orient` | `'rc'` / `'cr'` | `'rc'` | 先列后行 / 先行后列 |
| `Edge` | `'zero'` / `'symmetric'` / `'replicate'` | `'zero'` | 边界延拓方式 |
| `ZeroPhase` | `true` / `false` | `false` | 是否做前后向零相位滤波 |

对严格线性的可分离算子，`'rc'` 与 `'cr'` 的结果在数学上完全相同（矩阵乘法的
结合律），实测差异在 1e-15 量级。若两者出现明显差异，说明实现有误——本软件
把它作为一条内置的自检项。

`Edge` 影响边界附近的数值。`'zero'` 与原始题目的 `filter` 行为一致；
`'symmetric'` 与 `'replicate'` 能减少边界伪影，适合真实图像。

### 6.4 fl_shift —— 平移估计

```matlab
[dr, dc, peak] = fl_shift(Y, X)
```

用 FFT 计算二维循环互相关，返回 `Y` 相对 `X` 的整像素平移量。对齐时使用
`circshift(Y, -[dr dc])`。

线性相位滤波器的平移量应恰等于其阶数的一半（`n/2`），这也是一条可验证的
不变量。非线性相位滤波器没有单一平移量，互相关给出的是最小二乘意义下的
近似值。

### 6.5 fl_eval —— 指标计算

```matlab
R = fl_eval(X, Y, S)
```

返回字段：

| 字段 | 含义 |
|---|---|
| `Shift` | 平移量 [行, 列] |
| `Corr` | 互相关峰值（0–1） |
| `PSNRraw` | 未配准的 PSNR |
| `PSNR` | 配准后的 PSNR |
| `FlatRMS` | 平坦区残余均方根 |
| `EdgeMAE` | 边缘区平均绝对误差 |
| `OutEnergy` | 越界能量 |
| `ZeroCross` | 振铃密度 |
| `DynRange` | 输出动态范围 |
| `SymT` | 与自身转置之差 |

### 6.9 fl_filter_load —— 载入任意滤波器系数

把外部系数变成一个能放进 `S.Filters` 的规格项。

```matlab
sp = fl_filter_load(src, 'Name', '我的低通');
```

`src` 可以是：数值向量（当作 FIR）、元胞 `{b,a}`、结构体（自动找 `b/a`、`B/A`、`num/den`，或把 6 列 SOS 展开）、文件路径（`.mat` / `.csv` / `.txt` / `.dat`）。

返回项的关键字段：`Kind='coeff'`、`Name`、`B`、`A`、`Order`、`Source`。它会做四类校验：空系数、NaN/Inf、复系数、`a(1)=0`；然后统一把 `a` 归一化成首项 1。

**为什么要它**：原来的 `fl_spec` 只有三个写死的滤波器（一次 Butterworth + 两次 Parks-McClellan）。接入 `fl_filter_load` 之后，`Filters` 变成一个长度任意的列表，默认三项只是其中一组值，用户可以删、可以加、可以整组换掉——这是从“课程演示”走向“能算我自己滤波器”的那一步。

```matlab
S = fl_spec();
S.Filters = [S.Filters, fl_filter_load('mine.mat')];
out = FL_main(S);
```

**边界**：本函数只读系数，不做设计；如果指针不稳定或系数来自定点实现，量化误差要自己评估。IIR 一律按非线性相位处理（见 §6.2 的说明）。

## 7 指标定义与读法

### 7.0 通带增益（PassMin / PassMax）

第 1 问的表格里有一列"通带"，形如 `0.446~1.000`，它给出该滤波器在**通带内**
增益的最小值与最大值。理想低通在通带内增益应当处处等于 1。

- 若 `PassMin` 明显小于 1（例如 b2 的 0.446），通带内的细节被整体压低，照片上
  表现为"细节区发灰、像蒙了一层"。
- 若 `PassMax` 明显大于 1（例如 b3 的 1.375），通带内部分频率被放大，照片上
  表现为边缘出现一圈亮边或光晕。
- 软件在 `PassMin < 0.9` 或 `PassMax > 1.1` 时会自动打印告警。

这不是 bug，而是"阶数太低 + 过渡带太窄"的必然结果：5 个抽头做不出平坦通带。
把它读出来，比事后对着照片猜"为什么发灰"要快得多。

### 7.1 群延迟与线性相位

群延迟定义为相频特性的负导数：

```
τ(ω) = -dφ(ω)/dω
```

线性相位意味着相位是频率的线性函数，因而群延迟在所有频率上恒定。物理含义
是：所有频率成分延迟相同的时间，波形形状不被改变。

**读法**：`GDStd` 为 0（数值上小于 1e-9）即线性相位。`b2`、`b3` 的群延迟恒
为 2 与 6，正好是阶数的一半；`b1` 的群延迟随频率变化，标准差约 1.7。

### 7.2 阶跃响应与超调

超调定义为阶跃响应的最大值超出稳态值的部分，用百分比表示：

```
超调 = (max(y) - y_ss) / y_ss × 100%
```

**读法**：Butterworth 被称为"最大平坦"，但那说的是幅频特性在原点附近的平坦
程度，与时域超调没有直接关系。实测 b1 的超调最大（21.66%），b3 次之
（15.02%），b2 为 0。

`b2` 超调为 0 可以先验地推出：它的系数全为正，单调阶跃响应的叠加必然单调，
不可能出现超调。这条结论与实测一致，可以作为"数值结果可解释"的证据。

### 7.3 越界能量

```
E = mean([y - 1]_+^2 + [-y]_+^2)
```

衡量输出超出显示范围 [0,1] 的部分。显示范围外的值会被截断，截断即失真，因此
越界能量越大，图像的振铃越严重。

**读法**：b3（0.00662）略大于 b1（0.00565），b2 为 0。

### 7.4 振铃密度

```
ZC = 残差符号变化次数 / 像素总数
```

残差是输出与原图之差。数残差的符号变化，而不是数输出本身的过零——后者会
把边缘位置与整体亮度差也算进去，得到的是"边界过零数"而不是"振铃密度"。

**读法**：b3（0.1476）> b1（0.1424）> b2（0.0417）。

注意"振荡多"与"超调大"不是同一件事：b1 的超调更大，但 b3 的振铃更密——因为
二维滤波是行、列两次作用的累积，波纹的空间密度取决于阻带纹波的分布，而超调
取决于一维阶跃响应的形状。

### 7.5 镜像交换误差

```
D = max | filter(fliplr(X), h) - fliplr(filter(X, h)) |
```

线性相位等价于冲激响应偶对称，等价于"滤波与左右镜像可交换"。因此对线性相位
滤波器，上式恒为 0；对非线性相位滤波器则明显大于 0。

**实现注意**：因果滤波与"翻转输入"并不严格交换——`filter(flip(x))` 相当于把
`flip(filter(x))` 整体平移了一个阶数。直接相减会把两段错位的内容拿来比较，
线性相位也会算出很大误差。必须先配准再比较，并只统计内部区域以避开零延拓
边界。

**读法**：b1 = 0.4578，b2 = 0，b3 = 1.1e-16。这是"相位失真破坏形状对称性"
最干净的判据。

### 7.6 主对角对称性

行、列使用同一算子时，二维输出是 `Y = A·X·Aᵀ`。只要原图满足 `X = Xᵀ`，
就恒有 `Y = Yᵀ`——**与是否线性相位无关**。

**读法**：实测三个滤波器的 `‖Y - Yᵀ‖` 都在 1e-15 量级。因此报告里不能把
"主对角对称没有破坏"当成线性相位的证据；相位失真破坏的是**左右镜像**意义
下的对称（边缘两侧的振铃不同），不是主对角对称。这是本题最常见的概念性
错误。

### 7.7 PSNR

```
PSNR = 10 log10(1 / MSE)
```

在本软件中，PSNR 一律先配准再计算，并且只统计内部区域（默认裁掉四周 4 像素），
否则平移量与边界效应会把误差吃满。

**读法**（默认参数）：

| 处理 | PSNR |
|---|---|
| 未滤波 | 14.16 dB |
| b1 | 13.00 dB |
| b2 | 13.97 dB |
| b3 | 13.96 dB |

三者的整体 PSNR 全都低于不滤波。原因是这张图只有 3 像素宽的细线，噪声强度
并不大，任何 0.4π 低通把边缘糊掉的代价都超过降噪收益。

### 7.8 平坦区与边缘分解

整体 PSNR 会把"降噪"与"糊边"两种相反的效应混在一起。为看清取舍，软件把
误差分解为两部分：

- **平坦区残余 RMS**：远离边缘的像素上，输出与干净图的均方根误差，反映降噪能力；
- **边缘 MAE**：靠近边缘的像素上，输出与干净图的平均绝对误差，反映细节保留。

**读法**（默认参数）：

| 处理 | 平坦区残余 RMS | 边缘 MAE |
|---|---|---|
| 未滤波 | 0.1947 | — |
| b1 | 0.1140 | 0.2098 |
| b2 | **0.0461** | 0.2225 |
| b3 | 0.1129 | **0.1844** |

结论是：b2 降噪最强但边缘最糊，b3 边缘保真最好但降噪最弱，b1 两头居中。
只给一个"谁最好"的答案是不完整的，必须同时给出两组数字。

### 8.4 一个实测结果

| Wc | 滤波器 | 群延迟 | 标准差 | 超调% | PSNR | 振铃密度 |
|---|---|---|---|---|---|---|
| 0.25 | b1 | 5.352 | 3.528 | 19.63 | 10.52 | 0.0816 |
| 0.25 | b2 | 2.000 | 0.000 | 0.00 | 12.06 | 0.0417 |
| 0.25 | b3 | 6.000 | 0.000 | 14.26 | 11.86 | 0.0851 |
| 0.40 | b1 | 5.204 | 1.746 | 21.66 | 13.00 | 0.1424 |
| 0.40 | b2 | 2.000 | 0.000 | 0.00 | 13.97 | 0.0417 |
| 0.40 | b3 | 6.000 | 0.000 | 15.02 | 13.96 | 0.1476 |
| 0.45 | b1 | 4.743 | 1.320 | 22.07 | 12.80 | 0.1493 |
| 0.45 | b2 | 2.000 | 0.000 | 0.00 | 14.57 | 0.0417 |
| 0.45 | b3 | 6.000 | 0.000 | 0.00 | 15.25 | 0.0990 |

可读出的规律：

1. 截止频率越高，低通越"轻"，PSNR 单调上升，振铃密度也总体上升——因为保留
   的高频更多，边缘更锐利，但波纹也更细密；
2. 线性相位滤波器的群延迟标准差恒为 0，不随截止频率变化；
3. 非线性相位滤波器的群延迟**均值**变化不大，但**标准差**随截止频率下降

4. 超调与截止频率没有单调关系，它取决于时域形状，是设计的副产物。

### 8.5 一个重要约束

扫描截止频率时，群延迟的统计频带必须跟着走。早期版本把统计频带固定为
[0, 0.36π]，一旦 `Wc` 降到 0.25，这个频带已经整段落进过渡带甚至阻带，算出的
群延迟标准差毫无意义（会虚高到 5 以上）。当前版本按截止频率的 90% 动态确定
统计频带，并以上限 `PassW` 截断。

| 编号 | 检查内容 | 判据 |
|---|---|---|

| 2 | 等纹波性：通带纹波 ≈ 阻带峰值 | 比值 ≈ 1 |
| 3 | 线性相位：系数偶对称且群延迟恒定 | 均为 0 |
| 4 | 直流归一化：H(1) = 1 | 误差 < 1e-12 |
| 5 | 平移估计正确 | 估计值与真值一致 |
| 6 | 可分离一致性：`'rc'` 与 `'cr'` 结果相同 | 差异 < 1e-12 |

### 9.3 实测结果

| 检查 | 结果 |
|---|---|
| 1 | 通过，相对误差 4.43e-05 |
| 2 | 通过，比值 1.0008 |
| 3 | 通过 |
| 4 | 通过，H(1) = 1.000000000000 |

第 2 项最关键。等纹波设计的判据是"通带纹波的最大值等于阻带峰值"——这是

1.0008，再用手算的解析解交叉验证（δ = 0.37386），才确认实现正确。

一条可复用的经验：**数值算法必须有独立的判据，不能只看"跑通了、图出得来"。**

## 11 常见问题

### 11.1 运行时报"文本字符无效"

原因：MATLAB 以中文目录作为启动工作目录，或在命令行参数中传入了中文路径。

处理：先在英文路径下启动 MATLAB，再 `addpath` 中文路径；或把软件放到纯英文
路径下。

### 11.2 运行时报"输出参数太多"

原因：`sl_remez` 只有一个输出参数。等纹波设计返回的是分子系数，分母恒为 1，
因此没有第二个输出。

处理：写成 `b = sl_remez(...)`，不要写 `[b, a] = sl_remez(...)`。

### 11.3 奇数阶报错

原因：等纹波实现采用 Type I 线性相位结构，只支持偶数阶。

处理：FIR 阶数改成偶数。

### 11.4 PSNR 只有 3–6 dB

原因：没有做平移补偿，位移把误差吃满了。

处理：使用 `fl_eval` 或 `fl_report`，它们会自动配准。若自己写代码，对齐要用
`circshift(Y, -Shift)`——注意是负号，`Shift` 表示的是"Y 相对 X 被移了多少"。

### 11.5 镜像交换误差对线性相位也不为 0

原因：没有补偿阶数平移，或没有裁掉边界。

处理：见 7.5 节的实现注意。因果滤波与翻转输入相差一个阶数的平移，必须配准
后再比，并只统计内部区域。

### 11.6 界面点"运行分析"没反应

原因：正在计算中，按钮被禁用。

处理：等待计算完成。样例规模（32×32）通常在一秒内完成。

### 11.7 图像小于两倍阶数

现象：镜像交换误差与内部 PSNR 显示为缺失。

说明：这是预期行为。尺寸不足时内部区域为空，指标无定义。

## 12 创新设计：相位隔离、带弃权的决策、故障注入

前面第 1–11 章讲的是"怎么用"，这一章讲"这个软件做对了什么别人不容易做对的事"。三块内容都可以单独运行，入口是 `FL_innov`。

```matlab
out = FL_innov();                 % 全部跑一遍，出四联图
out = FL_innov(S,'Visible','on')  % 显示窗口
T = fl_phasetest(S);              % 只用模块 A
D = fl_decide(Xn,S,'Truth',X);    % 只用模块 B
M = fl_mutate(X,S);               % 只用模块 C
```

### 12.1 这三个模块解决的是同一类问题

课程里"设计三个低通滤波器，比较哪个好"通常停在指标罗列：谁的阻带深、谁的超调小。但真正难的是三件事：

1. **归因**——图像变糊了，是幅度特性造成的还是相位特性造成的？两个因素永远同时存在，只看输出分不开。
2. **决策**——滤了到底有没有好处？"滤一下总没坏处"是错的，第 12.3 节会给出实测反例。
3. **验证**——结论是算出来的还是凑出来的？一个只能跑出"好看结果"的脚本，和一套能证明自己没抄错的工具，是两回事。

三个模块分别对应这三件事。

### 12.2 模块 A：同幅频、不同相位的滤波器族

`fl_phasetest.m`

**原理。** 取一个线性相位 FIR 的系数 `h`，把它写成多项式 `H(z)=Σh[k]z^{-k}`，它的零点有一部分落在单位圆内、一部分落在单位圆外。对每个单位圆外的零点 `r`，替换成 `1/conj(r)`（反射到圆内），保持共轭对完整，再对系数重新归一化，得到一个新的滤波器。

关键恒等式是：

```
|e^{jω} - 1/conj(r)| = |e^{jω} - r| / |r|
```

右边只比左边多一个与 `ω` 无关的常数因子 `1/|r|`。归一化之后，这个常数也没了。**所以反射前后幅频特性逐点相同，差别全部落在相位上。**

反射圆外零点得到最小相位解，反射圆内零点得到最大相位解。这样就造出了一族"幅频一模一样、相位各不相同"的滤波器——它们是研究相位影响的理想对照物，因为可以保证唯一的自变量就是相位。

**解析预测的边缘位移。** 线性相位系统的群延迟是常数，位移量就等于群延迟。对一般的（非对称）滤波器，用脉冲响应的一阶矩来预测位移：

```
τ = Σ n·h[n] / Σ h[n]
```

**实测结果（默认参数，基准 b3）**

| 成员 | 群延迟 τ（解析） | 阶跃 50% 穿越（实测） | 穿越+0.5 − τ | 幅频最大偏差 | 阶跃超调 |
|---|---|---|---|---|---|
| 线性相位（基准） | 6.0000 | 5.5000 | 1.78e−15 | 0 | 15.02% |
| 最小相位 | 0.9039 | 0.5733 | +1.693e−01 | 2.22e−15 | 24.36% |
| 最大相位 | 11.0961 | 10.4267 | −1.693e−01 | 3.44e−15 | 0.00% |

三条判据都成立：

- 全族幅频重合，最大偏差 3.44e−15（浮点误差量级）；
- 对**对称**成员，"穿越+0.5 = 一阶矩"精确成立（差 1.78e−15）；
- 对**非对称**成员，两者分裂到 0.17 像素——这不是误差，而是"一阶矩只对对称核等于位移"的直接证据。

**一个必须知道的边界。** b3 的 13 抽头里有 12 个零点，其中 4 组（8 个）的模恰好等于 1.000000，也就是落在单位圆上。这些零点的反射是空操作（`r` 和 `1/conj(r)` 是同一个点），移不动。所以默认参数下这一族只有三个成员，不是四个。参数换成别的阶数才会有四个。

### 12.3 模块 B：带弃权的滤波决策器

`fl_decide.m`

**为什么"滤一下总没坏处"是错的。** 设原图 `x`、噪声 `n`（方差 σ²）、可分离算子 `L`。滤波后的误差可以精确分解为

```
E‖L(x+n) − x‖²  =  ‖(L−I)x‖²  +  σ²‖L‖_F²
                     └─偏差项─┘    └─残留噪声─┘
```

第一项是"结构被改坏了多少"（只跟图和算子有关），第二项是"噪声还剩多少"（只跟 σ 和算子有关）。两者反向：更强的低通压噪声更狠，但同时把结构改得更狠。**当噪声小到一定程度，第二项的收益就抵不上第一项的损失，滤波反而有害。**

**三项怎么算。**

- `‖L‖_F²`：对可分离算子有恒等式 `‖kron(A,A)‖_F² = ‖A‖_F⁴`，只要知道一维算子的 Frobenius 范数就能算，不用真的展开 n²×n² 矩阵。
- `‖(L−I)x‖²`：直接对 `x` 做一次滤波再相减。这里有个陷阱——**必须先配准**。滤波器会整体平移图像，不平移回来，`(L−I)x` 里就混进了"整体位移"，会被当成结构损伤，预测值直接掉 6–12 dB。配准后算子变成 `PL`（P 是循环移位矩阵），此时

  ```
  ‖PL−I‖_F² = ‖L‖_F² − 2·tr(PᵀL) + N
  tr(PᵀL)   = tshift(A,−dr,n) · tshift(A,−dc,n)
  tshift(A,s,n) = Σ_i A((i+s) mod n, i)
  ```

- `σ²`：从图像自身盲估。不能用差分中位数——本图约三成像素落在边缘上，边缘差分很大，中位数会被拉高 5.6%（估成 0.2112，真值 0.20）。改用 30% 分位：白噪声差分的绝对值服从半正态分布，30% 分位约等于 `0.5448σ`，反解得 0.2066。

**弃权规则。** 候选集里必须包含**恒等映射**（不滤波）。预测最优候选若不是恒等，且领先恒等的幅度超过裕量 `Margin`（默认 0.05 dB），才建议滤波；否则弃权。这个裕量的作用是把"几乎没差别"的情况一律判成弃权，避免在一张图上过度自信。

**实测结果（σ = 0.20，真值已知的合成数据）**

| 候选 | ‖L‖_F² | 偏差项 | 残留噪声 | 盲估计 | 模型(用真值) | 实测 |
|---|---|---|---|---|---|---|
| 不滤波（恒等） | 1024 | 0 | 43.703 | 13.698 | 13.698 | 13.969 |
| b1 | 106.3 | 23.243 | 4.539 | 15.665 | 15.400 | 15.209 |
| b1 零相位 | 160.5 | 13.756 | 6.851 | 16.963 | 16.752 | **16.849** |
| b2 | 67.1 | 21.102 | 2.864 | 16.307 | 16.082 | 16.221 |
| b2 零相位 | 41.41 | 28.006 | 1.768 | 15.365 | 15.231 | 15.418 |
| b3 | 180.7 | 15.615 | 7.712 | 16.424 | 16.122 | 15.857 |
| b3 零相位 | 492.5 | 35.849 | 21.019 | 12.554 | 12.674 | 12.351 |

这张表里有两行结论值得单独讲：

**（1）公式是对的。** 用真值算偏差项时，"模型"列与"实测"列平均只差 0.21 dB、最大 0.32 dB。分解式本身没有问题。

**（2）盲估计也是对的——但前提是把符号搞对。** 换成像的时候没有真值，偏差项只能用滤波输出反推，此时"盲估计"列与实测平均只差 **0.25 dB**、最坏 0.57 dB，而且它选中的 b1 零相位**就是**实测最优（16.849）。排序能力足够用。

这一条是开发过程中差点被写成"盲估计不可信"的地方，值得记下来：早期版本里 `tr(PᵀL)` 写成了 `tshift(A,−dr)`，而配准用的是 `circshift(Y,−[dr dc])`，两者符号必须一致，正确形式是

```
(Px)_i = x_{i+dr}   ⇒   tr(PᵀL) = Σ_i A_{i+dr, i}   （是 +dr，不是 −dr）
```

符号反了以后，因果候选的 `tr(PᵀL)` 被算成 0，`‖PL−I‖²_F` 被高估，偏差项被系统性压掉，盲估计整体偏高 1–1.9 dB、最坏差 3.63 dB，看起来就像"盲估计本来就不准"。修好之后误差降到 0.25 dB。**"理论上的局限"和"实现里的笔误"经常长得很像**，判断前者之前先排除后者。

所以本模块现在的定位是：**既回答"要不要滤"，也在本图上回答"选哪个"**；但因为它对符号约定敏感，换实现或换候选集时仍要用真值复核一次（`D.Caveat` 里写了这句）。

**交叉点。** 同一套图跑不同的 σ，全图域 PSNR 如下（不滤波 / b1 / b2 / b3）：

| σ | 不滤波 | b1 | b2 | b3 |
|---|---|---|---|---|
| 0.10 | 19.989 | 15.832 | 16.545 | 17.078 |
| 0.15 | 16.467 | 15.554 | 16.413 | 16.513 |
| 0.20 | 13.969 | 15.209 | 16.221 | 15.857 |
| 0.40 | 7.948 | 13.454 | 15.011 | 13.040 |
| 0.70 | 3.087 | 10.704 | 12.706 | 9.483 |

交叉点在 **σ ≈ 0.17** 附近：噪声低于它，任何滤波都不如不滤；高于它，滤波稳定带来收益。这条曲线就是"弃权"决策的物理依据。

### 12.4 模块 C：故障注入自检

`fl_mutate.m`

**为什么不满足于"结果看起来对"。** 一个脚本能出图、数字看着合理，并不说明它算对了——本软件在开发过程中就出现过三处"结果看起来完全正常"的错误：Remez 交换算法不收敛（纹波比 0.796，但图照样漂亮）、平移补偿方向写反（PSNR 塌到 5 dB，被当成"滤波本来就该差"）、`sl_filtfilt` 对行向量退化成恒等映射（零相位模式其实什么都没做，而且没有任何报错）。

**做法。** 人为往实现里注入 9 种典型故障，看自检能不能抓出来。关键设计是区分**有效变异**和**等价变异**：

- 有效变异：改变了系统行为，必须被抓到；
- 等价变异：数学上与正确实现完全等价，抓到反而说明检测器本身有误报。

等价变异不计入分母。否则"注入 9 个、抓到 9 个"这种漂亮数字，可能只是检测器太吵。

**4 个检测器**

| 编号 | 检测器 | 判据 |
|---|---|---|
| T1 | 常数图内部保持 | 输入全 1，内部区域输出应恒为 1 |
| T2 | 阶跃稳态回 1 | 阶跃输入的稳态值应为 1（直流增益为 1） |
| T3 | 位移一致 | 实测平移与解析 τ 预测相差不超过 0.5 像素 |
| T4 | 独立运算核对 | 与 Toeplitz 矩阵乘法的结果相差小于 1e−9 |

T4 是"用另一条完全不同的计算路径算同一个东西"，比自洽检验硬得多。

**实测结果：9 个变异，判定 9/9 全对，有效变异检出 6/6。**

| 变异 | 预期 | 被抓到 | T1T2T3T4 |
|---|---|---|---|
| （对称 FIR）系数倒序 | 等价 | 否 | 1 1 1 1 |
| （非对称 FIR）系数倒序 hA=[1 3 5 3 2]/14 | 有效 | 是 | 1 1 1 0 |
| IIR 反馈系数符号取反 | 有效 | 是 | 0 0 1 0 |
| 漏掉归一化（用未归一化系数） | 有效 | 是 | 0 0 1 0 |
| 输出量化到 0.01 | 有效 | 是 | 1 1 1 0 |
| 边界 zero 改成 replicate | 有效 | 是 | 1 1 1 0 |
| 整体平移 1 像素 | 有效 | 是 | 1 1 0 0 |
| 行列顺序交换 | 等价 | 否 | 1 1 1 1 |
| 先转置再滤再转回 | 等价 | 否 | 1 1 1 1 |

两个关于这张表本身的细节：

- **对称 FIR 的倒序是等价变异**，因为 `h = flip(h)` 对对称系数是恒等操作。要构造"倒序"这个真实的错误，必须换一个非对称核（表里用 `hA`）。
- **边界延拓的测试图必须边框非零**。原本用 plus 图直接测，它的十字四周留白 6 像素，零延拓和复制延拓在这张图上完全等价，故障永远抓不到；改用 `X+0.5` 才测出来。

### 12.5 三个模块各自的可信边界

写在这里，是因为不写清楚就等于夸大：

| 模块 | 能保证什么 | 不能保证什么 |
|---|---|---|
| A 相位隔离 | 幅频逐点相同（1e−15 量级），相位是唯一变量 | 只对单方向（一维）成立；零点落在单位圆上时全族成员会减少 |
| B 决策器 | "要不要滤"的判断稳定；分解公式本身经真值验证（0.21 dB）；盲估计在本图上也能选型 | **对 `tr(PL)` 的符号约定敏感**——写反了会被误读成"盲估计不可信"；换实现或换候选集必须用真值复核 |
| C 故障注入 | 能抓到实现类错误（归一化、边界、量化、平移、符号） | 抓不到"算法选型错误"，比如用了不合适的滤波器类型 |

`FL_innov` 的输出结构体 `out` 里依次是 `Phase`、`Decision`、`Mutation`，便于写进报告时逐项引用。
