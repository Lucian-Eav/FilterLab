# FilterLab Windows EXE（MATLAB 启动封装版）

本包包含真实 Windows EXE 启动器和应用代码。**需要本机已安装 MATLAB R2020b 或更新版本；仅安装 MATLAB Runtime 不够。** 本次实际测试环境为 Windows x64、MATLAB R2025b Update 1。

## 使用

1. 完整解压到普通文件夹，不要直接在 ZIP 内运行。
2. 双击 `FilterLab.exe`。首次启动需要等待 MATLAB 初始化，不会打开 MATLAB 编辑器。
3. 若没有自动找到 MATLAB，选择 MATLAB 安装目录中的 `bin\matlab.exe`。
4. 关闭照片工作室窗口后，本次启动的 MATLAB 后台进程会正常退出。

必须让 `FilterLab.exe` 与 `app` 文件夹保持相邻；不能只发送一个 EXE。可以为 EXE 创建桌面快捷方式。程序不需要管理员权限、不修改 MATLAB 安装或系统 PATH。

如果提示“低完整性工作区”，表示所在开发目录的 Windows 安全标签限制了 EXE。请把完整 ZIP 解压到普通用户文件夹，例如 `%LOCALAPPDATA%\FilterLab\Studio`，再运行里面的 EXE；不要直接运行开发工作区 `dist` 下继承了限制的构建副本。不需要关闭安全功能或修改原工作区权限。

自动查找顺序：包旁或用户配置的 `matlab-path.txt`、`MATLAB_ROOT` 环境变量、MathWorks 注册表、常规安装目录，最后检查构建机使用的 `D:\MATLAB`。文本配置一行写 MATLAB 的完整 EXE 路径即可。交付包不内置个人路径配置。

## 本次启动修复

启动器使用支持交互窗口的 MATLAB 会话，允许“打开照片”“导出照片”“保存参数”“载入参数”调用系统文件对话框。旧版 20261119-130731 使用了批处理启动参数，虽然界面能显示，但打开文件选择框会报“非交互或禁用窗口显示”；请关闭旧窗口，将新版 ZIP 重新解压到普通用户目录，并从新版目录启动。旧桌面快捷方式也需要重新指向新版 EXE。

## 保存位置

照片和参数保存位置由你选择；不覆盖原照片或已有目标。

默认数据目录为 `%LOCALAPPDATA%\FilterLab`：六问报告写入其中的 `output`，启动和错误日志写入 `logs`，每次启动使用独立日志目录。

若用户数据目录不可写，启动器自动使用 EXE 旁的 `userdata` 目录，日志、报告和 MATLAB 路径配置均随之切换，不修改系统权限。也可在 EXE 旁创建空文件 `portable.flag`，始终使用便携模式。两个位置均不可写时，程序会提示将完整软件包解压到自己可写的目录。

`app\samples\plus.mat` 已包含六问需要的 x/xn，不依赖原工作区目录。分发包不含个人照片及开发输出。

## 自检

从命令行执行：

```text
FilterLab.exe --self-test --test-output "D:\空的测试输出目录"
```

自检通过同一个 EXE 启动 MATLAB，创建应用界面、处理与导出合成照片、运行六问、生成报告及截图，然后退出。成功退出码为 0，输出目录包含 `PASS.txt`；失败读取启动日志。测试输出目录必须为空。

## 与真正独立版的区别

当前电脑没有安装 MATLAB Compiler（`mcc` 和 Compiler 构建 API 均不存在）。因此本包是调用已安装 MATLAB 的启动封装，**不是无需 MATLAB 的独立编译版**，也没有把 MATLAB 私有运行库复制进包中。

项目的 `deploy/build_standalone.m` 已提供独立版构建入口。安装合法授权、同版本 MATLAB Compiler 后，在项目目录运行 `addpath('deploy'); build_standalone`。生成的独立版只需要匹配版本的免费 MATLAB Runtime，仍需在目标机验证。Runtime 官方下载：https://www.mathworks.com/products/compiler/matlab-runtime.html

当前 EXE 未购买或配置代码签名证书，Windows 可能显示未知发布者。请只使用可信来源的包，无需关闭系统安全功能。
