# 用 FilterLab 完成原题六问

在 MATLAB 中将当前文件夹切换到 FilterLab，运行 `FL_gui`，点击顶部“题目滤波实验”标签或右上角“题目实验 →”，再点“运行六问并导出”。实验在同一个窗口显示，切回“照片与创意编辑”可继续原来的编辑。也可单独运行：

```matlab
FL_assignment_gui
% 等价入口：FL_main('assignment')

% 无界面生成报告；不填路径时自动创建新的 output/assignment-* 文件夹。
R = FL_assignment;
% 指定数据与一个不存在或为空的输出文件夹。
R = FL_assignment('DataFile', 'my_plus.mat', 'OutputDir', 'my_assignment_report');
% 仅计算：
R = FL_assignment('Export', false);
```

软件优先读取工作区题目目录中的 `plus.mat`，找不到时才使用项目 `samples/plus.mat`。也能在界面选择包含 `x`、`xn` 的 MAT 文件。输入数组尺寸应一致，最小为 16×16，数值须为有限实数。数据不会被归一化、重新加噪或裁到 [0,1]。

## 六问对应的结果

| 原题要求 | 软件提供的证据 |
| --- | --- |
| 1. 构造三个滤波器 | 固定原题 Wc=0.4、阶数 10/4/12、FIR 频带 [0 .36 .44 1]；列出完整 b/a 系数及其来源 |
| 2. 幅频、相频和线性相位 | 幅频、展开相位、通带群延迟、前 25 点冲激响应；明确两个 FIR 的线性相位 |
| 3. 阶跃响应与最大超调 | 三条阶跃响应，稳态线、峰值标记、绝对和相对超调 |
| 4. 原图按行列滤波与振荡 | 三种滤波器的输入、仅行滤波、行列滤波；中心剖面和范围越界诊断 |
| 5. 轮廓与对称性失真 | 原始剖面、补偿延迟和增益后的剖面、形状误差、镜像对称误差及非线性相位解释 |
| 6. 对 xn 重复实验与移动 | 直接使用给定 xn；三种指标口径的降噪比较，以及每个方向的延迟解释 |

图像显示统一使用 [0,1] 灰度范围；导出的 MAT 数组保留全部负值和过冲。第 1 页按原题 `image(64*x)` 显示原图。默认实验页嵌入照片工作室，切换不改变照片状态；`FL_assignment_gui` 仍可单独启动。照片侧栏的“滤波”工具采用适配照片的归一化双向处理，其结果不用于原题六问。

## 固定的实验口径

滤波使用原始系数，先 `filter(b,a,x,[],2)`（沿每一行），再 `filter(b,a,row,[],1)`（沿每一列），零初始状态。不做边界预填充、双向零相位处理或循环平移。这些约束用于复现题目的因果滤波行为。

原题的 FIR 并非直流增益恰好为 1。当前参考设计：Butterworth DC=1，4 阶 FIR DC≈1.373878，12 阶 FIR DC≈0.850094；行列级联的直流增益是上述数值的平方。额外归一化会改变题目实验，软件不会悄悄执行。

- 绝对阶跃超调：`max(step)-sum(b)/sum(a)`，稳态不假定为 1。
- 原坐标全图 MSE：直接比较滤波后的 xn 与 x，包含延迟、模糊、增益偏差和剩余噪声。
- 同域延迟补偿 MSE：4/12 阶 FIR 每轴分别补偿 2/6 像素。IIR 位移仅用干净图估计；每个候选比较固定区域。最终三个滤波器在同一有效参考区域比较，不使用 `circshift`，不让边界绕回。
- 同域增益校正 MSE：再除以 DC 增益的平方，只是分离增益因素的诊断，不能混称为原题滤波结果。
- 形状 MSE 使用干净输入的滤波结果；对称误差在位移补偿后的有限镜像像素对上计算。有限图像边界、截断和原图自身不完全对称也会影响该数值。

## 这份题目数据的实际结果

下列数值在 MATLAB R2025b Update 1 上用原题 32×32 的 x/xn 实际计算。FIR 使用下述等纹波备用系数。

| 滤波器 | 绝对超调 | 原坐标 MSE | 同域补偿 MSE | 同域再校正增益 MSE |
| --- | ---: | ---: | ---: | ---: |
| Butterworth 10 阶 | 0.216559 | 0.174565 | 0.043321 | 0.043321 |
| 等纹波 FIR 4 阶 | 0 | 0.206797 | 0.103458 | 0.033974 |
| 等纹波 FIR 12 阶 | 0.127471 | 0.143880 | 0.033570 | 0.037172 |

两个 FIR 具有线性相位；Butterworth 的群延迟随频率变化。Butterworth 的阶跃超调最大。本图估计 IIR 近似整体位移为每轴 5 像素，但一次平移无法抵消不同频率的不同延迟。

对给定 xn，原坐标和仅延迟补偿的 MSE 均由 12 阶 FIR 最小；额外校正直流增益后 4 阶 FIR 最小。这里必须带上比较口径，不能只说某个滤波器在一切意义下“最好”。这些结论仅对应题目样本，不能推广为自然照片的通用质量排名。

## 不安装附加工具箱也可运行

当前机器未找到 `butter`、`remez`、`firpm` 的可调用实现。软件使用解析 Butterworth 极点与双线性变换；两个 FIR 使用严格固定于原题参数的 Parks–McClellan 参考系数。这些 FIR 由 `scipy.signal.remez` 离线生成，网格密度 256、最多 100 次迭代、等权重、fs=2；软件运行时不依赖 Python。

每次运行会检查 FIR 系数对称性，以及通、阻带稠密网格上的交替极值数和纹波一致性。这个检查是数值证据，不是符号数学证明。报告会明确设计来源，不把备用系数写成当前机器执行过原生 `remez`。

如果安装了 Signal Processing Toolbox，自动优先使用 MATLAB `butter` 和 `remez`，新版缺少 `remez` 时使用 `firpm`。不同实现的设计网格可能带来末位数值差异。当前交付不提供任意阶数或截止频率的等纹波设计器；旧实验入口仍保留。

## 导出内容与复核

一次运行生成一个新目录，已有文件夹必须为空：

- `report.html`：完整六问报告、全部图示、系数来源与指标说明。在浏览器打开可用浏览器打印功能另存 PDF。
- `answers.md`：六问结论文字。
- `01-input.png` 至 `06-noise.png`：可直接用于实验记录的图示。
- `results.mat`：R、x、xn，含原始系数、频响、阶跃、行滤波/行列滤波数组和指标。
- `reproduce.m`：使用保存的完整系数独立复现全部干净图与含噪图的行列滤波，无附加工具箱要求。
- `original_design.m`：原题 `butter` / `remez` 设计语句（新版可用 `firpm`），需要 Signal Processing Toolbox。与无工具箱复现脚本明确区分。

报告中的结论来自计算结果。建议读着各问图像与指标复核解释，按课程要求补上个人分析。源 x/xn、照片原文件以及已有实验报告均不会被覆盖。
