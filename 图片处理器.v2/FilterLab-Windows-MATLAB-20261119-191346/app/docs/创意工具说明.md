# FilterLab 创意工具说明

运行 `FL_gui`。顶部两个工作区共用一个窗口：照片页保留原图、构图、参数、笔触和历史；题目页运行原题六问。切换页面不清空照片编辑。

右侧下拉菜单用于选择工具，避免在较窄的标签栏中逐个寻找。开始画笔或定位后，在图像上拖动，松开时提交计算；Esc 结束工具。每次笔触或定位只占一步撤销。

## 频域画笔

1. 选择“频域画笔”，点“在频谱上绘制”。
2. 在频谱的亮点或条纹上拖动。红色表示被抑制的频率，另一侧自动生成共轭笔触。
3. 点“查看照片 / 停止绘制”，检查实际照片；可切换分割对比或 100%。
4. 选择“恢复频率”后绘制可擦回衰减；“清空频域笔触”恢复全部频率。

频谱来自当前构图的**原图亮度**，不是最终效果的频谱。其中心为 DC，横纵坐标对应空间频率，最大绝对值为 0.5 周期/像素。笔刷半径采用频率单位，不是照片像素。平均亮度默认保护；共轭配对保持逆变换结果为实数。

适合观察、减弱周期性条纹或做方向性纹理实验，不是自动识别噪声。抹去大范围频率会同时损失真实结构，强抑制及图像边界可能产生振铃。先用小半径、较低强度，每笔后看照片。显示频谱时导出仍保存照片。

## 微缩景观

开启“启用微缩景观”，点“在照片上定位清晰带”，拖动确定中心。蓝色中线表示中心，旁边两线表示清晰带边界；它们仅用于操作，不会导出。

“清晰带宽”和“过渡宽度”相对于当前图像短边；“模糊半径”使用原图像素。“清晰带角度”控制方向。清晰区域保留输入，离开清晰带后逐渐模糊。俯拍街区、铁路、车辆往往更容易形成模型感；对风景则是选择性景深效果。

## 长曝光与运动

| 类型 | 有效参数 | 典型效果 |
| --- | --- | --- |
| 方向拖影 | 长度、方向角度、混合强度 | 线性运动、背景速度感 |
| 变焦拖影 | 变焦幅度、运动中心、混合强度 | 从中心向外扩张的轨迹 |
| 旋转轨迹 | 旋转角度、运动中心、混合强度 | 围绕中心旋转 |

“在照片上定位运动中心”用于变焦和旋转；方向拖影不使用中心。各类型只读取对应参数，切换类型保留其他参数以便返回。

这是单张照片的艺术模拟，不能恢复多帧真实长曝光的信息。为控制计算量，轨迹最多采用 41 次采样；较长轨迹或大角度可能出现重复轮廓。降低长度、幅度或混合强度可以减轻。

## 局部蒙版

蒙版是照片上的生效权重，可复用于所有创意工具，也可同时控制基础照片调整。

- “仅创意效果”：基础调色、去噪与锐化仍作用于全图，蒙版控制创意变化。
- “照片调整 + 创意效果”：未选区域保留当前构图的原图，选中区域应用完整流水线。

第一次开启空蒙版后需要涂抹，效果才会出现；也可以先“全选”，再擦除主体上的效果。红色标记生效区，不是最终照片颜色。

“画笔半径”相对于当前照片短边；不透明度控制每笔覆盖强度，羽化控制软边。可切换涂抹/擦除、反选、显示/隐藏，清空或全选。羽化支持绘制后调整。连续笔触通过路径补点连接，重复鼠标事件不会在同一笔中重复叠加不透明度。

空间笔触锚定于原照片，裁剪、90°旋转和翻转会同步变换蒙版；恢复构图可以恢复此前被裁掉区域上的笔触。原图和笔触均不会被破坏性写回。

例：先开启方向拖影，再进入蒙版、全选、选择“擦除生效区”，擦除人物区域，保留背景拖影。

## 照片中的题目滤波器

“照片滤波”可选择 Butterworth 10 阶、等纹波 FIR 4 阶或 12 阶，对照片亮度处理并调节混合强度。可用局部蒙版只处理天空或背景。

此处采用直流归一化、边界延拓及双向行列处理。每轴幅频响应变为原响应的平方，旨在保持常量亮度、减小相位位移。它不是原题的因果输出。

顶部“题目滤波实验”仍使用原始系数、零初态、先行后列的单向因果滤波。六问报告不受照片参数、蒙版、构图或创意效果影响。两种用途复用滤波器设计，分别明确计算约定。

## 顺序、预览与导出

完整处理顺序为：原图重放构图 → 基础照片调整 → 照片适配滤波 → 频域滤波 → 微缩 → 运动 → 蒙版混合。开关为关闭时跳过相应模块，组合效果按此顺序计算。

一般适应窗口先缩图再处理，位于短边/像素尺度的创意参数会随预览比例换算。频域、照片适配滤波或自动估噪开启时，使用完整图像计算后缩小展示。100% 与导出总是按完整分辨率计算。较大照片的 FFT 或运动效果可能需要等待，界面会进入忙状态。

频谱原始缩略图在构图不变时复用；频域笔触只重建衰减叠加层。调色或微缩不会重新计算原图频谱。几何变化会失效相关缓存。小照片可直接复用完整尺寸预览供 100% 与导出使用。

导出既不含蓝色引导线、红色蒙版、频谱或残差，也不含界面边框。只能保存为新的文件，始终保护原文件。

## 预设与历史

参数预设保存基础调整、创意参数和频域笔触。空间蒙版依赖当前照片，保存预设时不包含其启用、笔触及其他蒙版状态；载入预设保留当前照片的空间蒙版。预设不包含构图和历史。旧照片预设仍可读取，缺失的创意模块默认为关闭。

撤销/重做同时覆盖参数、构图和笔触，最多 50 步。新打开照片会清空旧历史及创意设置。关闭窗口后没有自动项目恢复；需要保留结果请导出，需要复用通用设置请保存参数。

实际通过的测试、截图与导出样例见 [验证记录](照片版验证记录.md)。
