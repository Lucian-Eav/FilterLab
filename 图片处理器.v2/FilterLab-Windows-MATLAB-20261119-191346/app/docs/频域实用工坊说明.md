# 频域实用工坊

FilterLab 的第四工作区提供连拍堆栈、清晰度体检、频域隐形水印和光学星芒与散景。兼容目标为 MATLAB R2020b+，本机使用 R2025b Update 1 验证。六个 `fl_ft_*` 核心文件仅使用 MATLAB 基础函数。

## 启动与照片输入

在工程根目录执行以下命令。

```matlab
addpath('app','app/core');
FL_photo                            % 顶部选择“频域实用工坊”
FL_freqtools_gui                     % 独立窗口
FL_main('freqtools')                 % 总入口打开工坊
```

主窗口首次选中「频域实用工坊」时创建嵌入面板，再次进入复用当前结果。四页分别提供样例、输入、运行和导出按钮。

照片输入支持 RGB/灰度数组、数值图像元胞、照片文件单元格列表和文件夹路径。文件夹扫描 JPEG、PNG、BMP、TIFF，文件读取复用 `fl_photo_load`，处理数据统一为有限 double RGB `[0,1]`。整数数组按其类型最大值归一化。连拍堆栈要求各帧尺寸一致。

默认处理最长边上限为 512 px，清晰度频谱计算再限制到 384 px。**导出保存实际处理尺寸**，堆栈还会按公共区域裁剪。CLI 的 `MaxEdge` 与 GUI 构造参数 `MaxEdge` 可调整处理上限。`flintmax` 可用于保留输入尺寸。

```matlab
R = FL_freqtools('burst', {'01.jpg','02.jpg','03.jpg'}, ...
    'Mode','median','MaxEdge',1024,'SaveTo','stack.png');
R = FL_freqtools('sharpness', 'D:\照片\旅游连拍');
R = FL_freqtools('watermark', 'landscape.png', ...
    struct('Text','MY PHOTO 2026','Strength',0.22), 'SaveTo','signed.png');
R = FL_main('freqtools-run','optics','Aperture','pent5');
```

选项支持结构体和名值对混用。`Input` 也可指定输入，`Sample` 指定内置样例，省略输入自动选择对应样例。`SaveTo` 通过 `fl_photo_save` 保存 PNG/JPEG/TIFF，保护输入照片和已有目标文件。输出包含模块结果、`InputMeta`、`InputImages`、`Tool` 与 `SavedTo`。

## 连拍对齐与堆栈

二维 Hann 窗和去均值降低边界频谱泄漏，温和径向权重抑制高频噪声。归一化互功率谱的逆 FFT 给出平移峰，三点抛物线插值细化到亚像素。PSR 表示主峰相对旁瓣的显著程度。

`Shifts(k,:)` 是第 k 帧相对参考帧的观测位移 `[dy dx]`。对齐通过 `interp2(frame,x+dx,y+dy,'linear',NaN)` 把采样位置移回参考坐标。`Aligned` 沿第四维存放各帧，`CropRect` 使用 `[x y width height]`。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `Mode` | `median` | 中位数去移动路人，`mean` 均值降噪，`trimmed` 去掉最大与最小值后均值 |
| `RefIndex` | 1 | 参考帧索引 |
| `AutoCrop` | true | 裁至全部帧公共有效矩形 |
| `Clean` / `TrueShifts` | 空 | 可选量化真值，仅用于结果评价 |

GUI 可分别点击「使用去路人样例」和「使用夜景降噪样例」，模式会同步切换。运行后显示参考帧、堆栈、亮度差异热图、末帧对齐图和位移/PSR 表。

`Metrics` 包含帧间亮度残差、噪声标准差下降率及最大位移。提供真值时，在一致的参考坐标区域比较单帧与堆栈的 RGB PSNR、SSIM、残差标准差。自备照片的噪声量使用亮度对角差分 MAD 估计。

## 连拍清晰度体检

统一频谱尺度后计算中高频能量占比 `HFRatio` 与对比度归一化频谱二阶矩 `SpectralMoment`，以二者乘积的平方根作为 `RawScore`。组内最高得分归一为 100，`Table` 按得分降序排列，`BestIndex` 与 `Spectra` 使用原始输入索引。

18 个角度扇区覆盖 0° 至 170°。利用组内推荐帧的扇区能量归一化场景本身的方向结构，再从二阶圆谐波拟合保留高频的亮脊，旋转 90° 得到手抖衰减方向。方向性与各向异性阈值共同控制中文诊断。`ShakeAngle` 采用图像坐标的顺时针角度，水平向右为 0°，周期为 180°。未达到方向性阈值的帧返回 NaN。

点击排名表任意行，可对比该照片、该帧二维对数功率谱、推荐照片和推荐频谱。「导出最清晰照片」保存处理尺度下的推荐 RGB 像素。

## 频域隐形水印

内置 5×7 点阵支持 A–Z、0–9、空格、`- _ . !`。输入小写字母会转换为大写。图标支持 `heart`、`star`、`smile`、`plus`，自定义 `PatternImage` 可为图像数组或文件路径，按亮度阈值生成模板。

水印置于上半平面中高频矩形，并通过以 `floor(H/2)+1`、`floor(W/2)+1` 为中心的共轭坐标精确配对。算法叠加幅度增量并保留复数频谱相位，逆 FFT 后将亮度差加回 RGB。默认 `Strength=0.22`，支持 0.05 至 0.60。

```matlab
R = FL_freqtools('watermark','Text','FILTERLAB');
R = FL_freqtools('watermark','Mode','icon','Icon','heart');
V = FL_freqtools('watermark','signed.png','Action','inspect', ...
    'Text','MY PHOTO 2026');
```

「仅查验当前图频谱」对当前加载的输入照片计算二维对数幅度谱和模板区域相关性。保存后重新打开照片即可独立查验，使用与写入时一致的图像尺寸、文字或图标设置。`DetectCorr` 为模板与区域对数幅度谱的归一化相关系数，`DetectSNR_dB` 使用模板前景与背景统计量。

`RunAttackTest=true` 同时验证高斯噪声 σ=0.015 和 `0.95*I+0.04` 亮度对比度扰动，结果在 `Attack.Noise`、`Attack.Tone`。GUI 显示两种扰动的检出相关性，并展示加噪后的水印区域。攻击测试使用局部随机流。

## 光学星芒与散景

星芒通过真实孔径的零填充二维 FFT 计算夫琅禾费衍射强度。细孔径网格保留直线叶片边缘，柔和抑制中心主峰、压缩衍射翼后归一化为 PSF。散景以旋转后的几何孔径作为离焦 PSF。

| 参数 | 默认值 | 含义 |
| --- | --- | --- |
| `Effect` | `starburst` | 衍射星芒，或 `bokeh` 几何散景 |
| `Aperture` | `hex6` / `heart` | 星芒有 `hex6`、`oct8`、`pent5`、`cross4`，散景有 `heart`、`star`、`hexagon`、`ring`、`custom` |
| `Threshold` | 0.78 | 线性光高光阈值，范围 0.40–0.98 |
| `Intensity` | 0.85 | 线性光叠加强度，范围 0–2.5 |
| `Size` | 45 / 15 | 星芒核尺寸参数，实际核采用奇数边长，散景为半径 |
| `RotationDeg` | 15 | 孔径旋转角度 |
| `Dispersion` | true | 星芒 RGB PSF 按 1.06 / 1.00 / 0.94 波长比例缩放 |
| `CustomAperture` | 空 | 自定义散景孔径的文件路径或数组 |

5 叶片孔径产生 10 个衍射方向，6、8、4 叶片分别对应 6、8、4 个方向。sRGB 经 2.2 次幂转线性光，平滑高光门控后进行零填充 FFT 线性卷积，再以带肩部压缩的光能增量叠加。

`PSFKernel` 是能量归一化数值核，`PSF` 是对数压缩的 RGB 展示图。`Metrics.EnergyIncrease` 为线性光平均增量，`DarkBackgroundError` 为所有暗像素的平均亮度变化，包含高光周围新增的光芒。自检另在卷积支持范围外的纯暗区验证背景稳定。

```matlab
R = FL_freqtools('optics','Aperture','pent5','RotationDeg',15);
B = FL_freqtools('optics','Effect','bokeh','Aperture','heart','Size',15);
F = FL_freqtools_gui('Visible','off','MaxEdge',768);
```

## 确定性样例与自动化接口

`fl_ft_samples` 提供五套合成样例。`burst_crowd` 为 7 帧含移动路人的手持连拍，`burst_night` 为 8 帧夜景噪声连拍，`burst_sharpness` 为 6 帧打乱的对焦/手抖退化图，`watermark_photo` 为细节风景，`night_lights` 为高反差点光源夜景。样例生成自动恢复调用者的 rng 状态。连拍元数据包含干净图、真实位移或锐利帧索引和退化标签。

独立窗口和嵌入面板均提供 `FreqToolsActions` 与 `FreqToolsState`。嵌入时同一接口也发布到宿主窗口。

```matlab
f = FL_freqtools_gui('Visible','off');
cleanup = onCleanup(@()delete(f));
a = getappdata(f,'FreqToolsActions');
a.UseSample(1,'burst_night');
R = a.RunModule(1);
a.SetInput(2,{'01.jpg','02.jpg'});
a.RunModule(2);
a.SelectRank(2);
a.SetOptions(4,struct('Effect','bokeh','Aperture','heart'));
a.RunModule(4);
a.Export(4,'bokeh.png');
state = getappdata(f,'FreqToolsState');
```

工具索引为 1 堆栈、2 清晰度、3 水印、4 光学。`RunAll()` 顺序运行四页当前输入，`Inspect()` 查验第 3 页输入，`SetModule(id)` 切换页签。`State` 包含 `Busy`、`SelectedModule`、`Results`、`Inputs`、`Samples`、`SelectedRank`、`MaxEdge`。运行按钮和程序接口共用实现，计算期间保护重入和关闭，异常后恢复忙碌状态。
